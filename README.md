# 💼 Portfólio — Fellipe Dourado

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, conhecimentos, projetos e evolução na área de tecnologia.

## Sobre o projeto

Este portfólio reúne informações sobre minha formação em Ciência da Computação, conhecimentos técnicos, projetos e materiais relacionados à minha trajetória na área de tecnologia.

O projeto também faz parte da minha prática em desenvolvimento web, permitindo aplicar conhecimentos de HTML e CSS na construção e organização de uma interface própria.

## Conteúdo

O portfólio está organizado em diferentes áreas:

-  Front-End
-  Back-End
-  Infraestrutura
-  Lógica
-  Formação
-  Currículo

## Tecnologias utilizadas

- HTML5
- CSS3
